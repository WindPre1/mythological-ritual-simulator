Mythological Ritual skins
=========================

Put one file per mob in this folder (or in the path set as skins-folder in config.yml).

Accepted names (any of these):
  HUNTER.png     or MinosHunter.png     or Minos_Hunter.png
  LYNX.png       or SiameseLynxes.png
  NYMPH.png      or StrandedNymph.png
  BULL.png       or CretanBull.png
  HARPY.png
  GAIA.png       or GaiaConstruct.png
  MINOTAUR.png
  CHAMPION.png   or MinosChampion.png
  INQUISITOR.png or MinosInquisitor.png
  SPHINX.png
  MANTICORE.png
  KING.png       or KingMinos.png

File types:
  .png  — skin texture. If it is a Mojang/Hypixel CDN texture, it will apply.
  .txt  — a single 64-char texture hash (from textures.minecraft.net/texture/<hash>)
  .url  — a full texture URL

Default lookup path (Windows practice server):
  C:\Users\WindPre\Downloads\Diana Practice Server\MythoSkins
